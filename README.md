# MessageSeeker.discordBot

MessageSeeker Discord Bot

Bot de Discord em Python (discord.py) que busca no histórico do chat, ao vivo, sem persistir mensagens, parando quando encontra algo parecido com o termo pedido.

Tecnologias
Python 3.12
discord.py
Docker
GitHub Actions (CI: testes + build da imagem)
Deploy: Railway
Rodando localmente
Pré-requisitos
Python 3.12+
Docker (opcional, para rodar em container)
